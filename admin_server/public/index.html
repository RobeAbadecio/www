Local Admin

This admin interface is only available on this PC (localhost binding). Provide your credentials to continue.

Upload project (zip)

Upload a .zip and it will be extracted into the WAMP www folder under the given destination name.

Add web-app to dashboard

Enter a title and the link relative to WAMP's www (for example: my-app/index.html).

Remember: server binds to localhost only. To secure it, set ADMIN_USER and ADMIN_PASS environment variables before starting.
