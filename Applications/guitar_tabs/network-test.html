Instructions to Access from iPad

Step 1: Find Your Computer's IP Address

On your Windows computer, open PowerShell and run:

ipconfig | Select-String "IPv4"

Look for an IP like 192.168.1.x or 10.0.0.x

Step 2: Configure WAMP to Accept Network Connections

  1. Click the WAMP icon in your system tray (bottom right)
  2. Go to Apache → httpd.conf
  3. Find the line: Require local
  4. Change it to: Require all granted
  5. Save and restart Apache from the WAMP menu

Step 3: Allow Windows Firewall

Make sure Windows Firewall allows Apache:

  1. Search for "Windows Defender Firewall"
  2. Click "Allow an app through firewall"
  3. Find "Apache HTTP Server" and check both Private and Public
  4. Click OK

Step 4: Access from iPad

On your iPad browser, go to:

http://YOUR_COMPUTER_IP/Applications/guitar_tabs/index.html

Replace YOUR_COMPUTER_IP with the IP address from Step 1
